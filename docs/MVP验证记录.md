# 山月 MVP 验证记录

日期：2026-11-13

交付物：项目根目录 `index.html` 为手机网站首页，`offline.html` 为独立阅读文件，收录 17 篇代表作品。

## 已完成验证

内容校验通过：作品标识唯一；作者、分类、专题、关联作品的引用完整；选句位置有效；各篇具备原文、字词、背景、赏读、思想与资料信息；分类无循环；交付 HTML 与内容源一致，核心资源无网络依赖。

在独立 Chrome 测试环境中，11 组核心流程通过：

1. 屏蔽 HTTP/HTTPS 请求后，直接打开本地 HTML，首页正常呈现。
2. “月 + 思念 + 李白”组合筛选返回《静夜思》，层级标签与搜索正确组合。
3. 原句注释、展开赏读、收藏及刷新后的恢复正常。
4. 竖版和方形 PNG 实际下载，尺寸分别为 1080×1440、1080×1080。
5. 长篇全文超出卡片容量时显示提示并禁用保存，切换摘句后恢复。
6. 作品、句子与阅读留念分别展示；重复下载不重复增加记录。
7. 模块隐藏、新增自定义模块、填写内容在详情中生效。
8. 分类新增、父分类设置和作品标签调整正常。
9. 个人备份可导出并恢复；带循环分类的文件被拒绝，现有数据未改变。
10. 导出的阅读 HTML 可独立打开，不携带个人收藏；390px 与 320px 布局无横向溢出。
11. 上述流程无未捕获的浏览器脚本异常。

补充的 3 组验证通过：

- 收藏后的原文发生修改，原有句子收藏制卡仍使用保存时的选句。
- 导入赏读中的 HTML 字符串按文本显示，不创建可执行节点。
- 完整短诗可在素笺、月夜、草木三种样式与两种比例下导出，均未发生内容溢出。

已人工查看电脑首页、作品详情、手机首页、手机制卡界面与实际导出的分享卡。最后增加触屏设备的按钮点击区域，并单独检查触屏窄屏布局。

```sh
python tests/pwa_smoke.py
python tests/pwa_smoke.py --root
```

测试脚本需要独立安装的 Python Playwright 和本机 Chrome。用户使用交付 HTML 无需这些工具。

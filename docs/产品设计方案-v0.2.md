# 古诗文卡片阅读：产品设计讨论稿

- 版本：v0.2.1（补充分享卡与自愿阅读打卡）
- 日期：2026-11-13
- 状态：用户已确认；已实现首个 MVP，具体范围见项目 README。本文保留完整产品方向，后续按预览反馈迭代。
- 定位：以作品为中心，通过卡片阅读和文学关联，激发兴趣、传播文学种子的古诗文阅读工具。
- 本稿替代 v0.1，后续设计与实施以本稿及用户进一步反馈为准。

## 1. 产品意图

让读者先被一句诗、一种景色、一份心情吸引，愿意读完一篇作品，再自然地走向另一篇。知识解释帮助阅读发生，分类帮助读者发现联系，交互给读者自由探索的空间。

儿童、青少年及陪伴阅读的家长是重要使用者，也欢迎任何对古诗文有兴趣的人。进入页面后即可阅读，无需先选择年级、设置学习目标或完成任务。

### 已确认的约束

| 项目 | 设计方向 |
| --- | --- |
| 内容起点 | 全国中小学古诗文范围作为首批内容整理基础，允许扩充教材外的优秀作品 |
| 学段信息 | 只保留“小学／初中／高中”等轻量标签，可为空或多选 |
| 内容组织 | 主要依据作品的情感、景物、题材、风格、流派、作者等文学特征 |
| 内容详解 | 保留原文、作者生平、背景、创作手法、思想情感等，按需展开 |
| 交互目标 | 邂逅作品、细读文字、发现关联、收藏与重读，生成图片留念和分享 |
| 配置 | 页面内可增删改分类和内容模块，支持内容与配置的导入导出 |
| 交付 | 单文件 HTML，手机、平板、电脑适配，核心阅读可离线使用 |
| 当前阶段 | 已确认方案，交付首个 MVP 供预览 |

首版不建设教材目录、册次导航、教学目标、考点、必背清单、练习考核、掌握度、复习队列、连续打卡任务和积分。这些功能从产品范围中移除，不通过改名继续保留。

支持用户主动记录“今天读到的文字”，生成带日期、选句和个人感受的精美图片，用于保存、自愿打卡和分享朋友圈。记录是阅读留念，无需设置目标或维持连续天数。

## 2. 阅读体验

### 2.1 先遇见作品

首页直接呈现作品卡。短诗完整展示，长诗与古文显示有完整语意的片段，并明确标注节选和“阅读全文”。题名、作者、原文构成视觉中心。

读者可以继续读、换一篇、收藏，或者沿某个景物、心情或作者进入更多作品。首页推荐以编辑精选和当前选择的主题为基础，随机切换作为辅助，避免短时间内反复出现同一篇。

首屏无需先展示主旨结论。给读者留下自己的第一感受，解释在他想了解时出现。

### 2.2 愿意停下来时，可以读深一点

点击不熟悉的字词，出现简短解释；点击“作者”“背景”“赏读”等入口，再逐步展开更丰富的内容。

作品仍是阅读的中心：查看注释或赏读后能够回到刚才的诗句，长文保留位置。讲解可以具体而深入，但从眼前的文字出发，不要求读者记住术语和结论。

### 2.3 读完一篇，还有自然的去处

每篇给出少量明确、有理由的关联，例如：

- 同一轮月，在不同诗人笔下是什么模样。
- 同一位作者，在另一段人生里写下了什么。
- 同样写送别，一篇不舍，一篇开阔。
- 同一个意象，如何在诗、词和古文中发生变化。

推荐卡说明关联理由，例如“也写月色，却把目光留在山涧的声音里”。理由需由内容支持，不能只显示空泛的“猜你喜欢”。

阅读随时可以结束，再打开时可继续上次的位置。收藏保留“我喜欢什么”，不转化成待完成任务。

遇到喜欢的文字，可以点击“生成分享卡”，挑选句子、样式和可选内容，预览后保存图片。日期和读后感由读者决定是否展示；生成卡片不要求公开分享。

## 3. 内容分类：严谨的底层，轻松的入口

### 3.1 多维、多级分类

每个维度内部可以有多级分类；一篇作品可以关联多个维度和多个标签。通常展示两到三级，其余层级按需展开。

| 维度 | 层级示例 | 阅读作用 |
| --- | --- | --- |
| 景物与意象 | 天象气象 → 风／雨／雪／霜／云／月／日／星；山川水域 → 山／江／河／湖／海／溪／瀑；植物 → 花 → 梅／荷／菊／桃；植物 → 树木 → 柳／松／柏；动物 → 雁／燕／鹤／蝉；人文景物 → 楼台／舟／桥／城关 | 从一个熟悉的事物出发，看到不同作品中的变化 |
| 情感与心境 | 思念 → 思乡／怀人／思亲；喜悦 → 闲适／欢欣；人生感怀 → 孤独／惆怅／旷达／惜时；家国 → 忧国／忧民／报国 | 找到能与当下心情呼应的文字，观察作品中的情感转折 |
| 题材 | 山水田园／羁旅行役／送别赠答／怀古咏史／边塞／咏物／节令民俗／人生哲思 | 认识作品写了什么、关注怎样的生活 |
| 时令与场景 | 四季 → 春／夏／秋／冬；时段 → 清晨／黄昏／夜晚；场景 → 山居／江行／雨夜／田园；节日 → 清明／中秋／重阳等 | 让阅读与日常所见、时节变化产生联系 |
| 作者与时代 | 朝代或时期 → 作者 → 作品 | 认识具体的人，沿着作品了解其生命经历 |
| 文学流派 | 诗歌 → 山水田园诗派／边塞诗派／江西诗派；词 → 豪放派／婉约派；散文 → 桐城派等 | 在有依据时提供文学史脉络，允许不归入特定流派 |
| 艺术风格 | 清新自然／雄浑豪放／沉郁顿挫／婉丽含蓄／浪漫奇崛等 | 发现语言、气质和表达方式的差异 |
| 体裁 | 诗 → 古体诗／近体诗 → 律诗／绝句；词；曲；古文 → 记／说／论／序／表／书；辞赋 | 保留不同文学形式的特点 |
| 表达手法 | 修辞 → 比喻／拟人／夸张／用典；表现 → 情景交融／托物言志／虚实结合／动静结合；结构 → 照应／转折等 | 支撑细读与进阶探索，讲清具体文字的妙处 |

朝代、作者、流派、风格分别维护，不混入同一类别。作品级与诗句、段落级标签都可以存在；每项解读应能找到原文或可信资料的支持。

### 3.2 分类如何出现在界面中

常用入口优先展示“风、花、雪、月、山”“思念、欢喜、孤独、旷达”“春日、雨夜、远行”等易感知的内容。完整分类在“寻篇”中按需查看，不在首页堆满标签和筛选器。

可编辑的专题把多个分类组合成一组阅读路径，例如“月色里的不同心事”“雨声中的人间”“山中有回响”。专题有简短引言、选篇和关联理由，收录数量随内容需要决定，不强行凑数。

专题与分类分开维护：分类负责准确组织，专题负责一次具体的阅读邀请。作品在多个专题中出现时，仍引用同一份正文与详解。

### 3.3 标签与搜索规则

- 景物可标记实写、想象、回忆、比喻或典故等出现方式。例如《静夜思》的“霜”是比喻中的景象。
- 不将“月”固定解释为思乡，也不将同一作者的所有作品归为同一种风格。
- 父分类包含子分类；同一维度多选默认任一符合，不同维度之间默认同时符合；作品去重显示。
- 搜索支持题名、别名、作者、首句、原文与标签，并显示命中片段。
- 没有分类的作品仍可以从全部作品或搜索访问。

“小学／初中／高中”只在作品的辅助信息或可选筛选中作为普通标签出现，不成为分类树、导航主轴或阅读门槛。标签不表示读者能力，也不影响默认讲解深度；无可靠依据时允许不标。教材外作品以同等阅读地位融入内容，不增加醒目的教辅身份标识。

## 4. 卡片与详情内容

### 4.1 作品卡

建议的阅读顺序：题名与作者 → 原文 → 少量主要意象或情感标签 → “读一读／收藏／换一篇”等操作。“生成分享卡”作为次要操作，可从作品详情、选句或收藏进入。

短篇优先直接读完整内容，长篇卡片使用经过选择的原文片段，不截断到语意不明的位置。节选必须有明确标识，详情可查看完整原文及结构关系。

卡片是阅读的容器。翻面可以承载简短的赏读或背景，但完整原文和长文详解都要有清晰的展开入口，不能依赖复杂手势或固定高度。具体是否使用翻面动效，在后续样例设计中选择。

### 4.2 可配置的详情模块

| 模块 | 内容与表达方式 | 默认呈现 |
| --- | --- | --- |
| 原文 | 保留诗行、段落、序文、组诗关系与必要异文说明 | 核心内容，直接显示 |
| 字词与译意 | 生僻字读音、词义、典故、句意；解释与对应文字相连 | 点击字句查看，也可展开集中阅读 |
| 作者 | 简介、重要经历、代表作品及与本篇有关的身世；佚名或集体作品如实说明 | 先简述，完整生平按需展开 |
| 写作背景 | 时代处境、时间地点、写作缘由；区分已知事实与不确定说法 | 按需展开，以理解作品所需的信息为主 |
| 赏读 | 从具体语句观察画面、节奏、结构、创作手法、思想与情感变化 | 先给简短观察，再提供深入细读 |
| 景物与意象 | 出现的位置、方式、在本篇中的作用及关联作品 | 与原文和分类联动 |
| 结构与脉络 | 长文叙事、论说的推进，诗词的照应、转折 | 适用于作品时提供 |
| 关联阅读 | 同景物、同作者、同题材或有意味的差异，每项写明关联理由 | 正文之后展示少量推荐 |
| 出处与资料 | 原文版本、参考资料、争议说明 | 放在资料信息中，随时可查 |
| 自定义模块 | 如“同题异作”“一处地名”“后世回响” | 用户可增删改、排序、启停 |

原需求中的作者生平、背景、创作手法和核心思想均保留。思想与情感放在具体细读中展开，允许有依据的不同理解，不把一篇作品压缩成唯一的“中心思想答案”。

### 4.3 内容写作原则

1. 先让人读到作品，再提供帮助。讲解清楚、具体，避免每篇套同一种答题模板。
2. 用作品中的细节激发兴趣。例如解释“月出惊山鸟”时，可以从月亮升起、山鸟惊动和山涧的声音说起，再谈动静关系。
3. 作者生平与背景有史实依据，不为趣味补写对话、心理活动或传奇故事。
4. 赏析区分事实与解释；创作时间、作者归属和思想阐释存在争议时保留余地。
5. 不按学段自动隐藏深入内容。以简述和展开满足不同阅读需求，读者决定停留多深。
6. 景物插画、音频等可以辅助体验，但文字自身要足以成立；装饰不应替代原文阅读。

## 5. 一段具体的阅读示例

读者从“月”进入，看到几篇作品：

| 作品 | 原句示例 | 可以继续探寻的方向 |
| --- | --- | --- |
| 王维《鸟鸣涧》 | 月出惊山鸟，时鸣春涧中。 | 月光、声音与山中的夜色 |
| 李白《静夜思》 | 举头望明月，低头思故乡。 | 眼前的月色如何牵动远方的思念 |
| 苏轼《水调歌头·明月几时有》 | 但愿人长久，千里共婵娟。 | 相隔千里的人如何借月光彼此牵念 |

这些观察是阅读邀请。读者可以点击一句查看字词，打开作者简介，读完整作品，或者沿“山中的夜色”换一个方向继续读。没有答题、自评或完成专题的要求。

这样的设计既保留多级分类和详细内容，也让分类成为作品之间的路。

## 6. 导航、移动端与视觉

建议设置三个主入口，设置独立收纳：

| 入口 | 内容 | 主要操作 |
| --- | --- | --- |
| 随读 | 直接阅读作品卡，少量精选专题，继续上次阅读 | 读下去、换一篇、收藏、沿标签探索 |
| 寻篇 | 搜索、全部作品、多维分类、作者和专题索引 | 按景物、心情、作者等发现作品；按需组合条件 |
| 收藏 | 喜欢的作品、句子、自建收藏夹与自愿保存的阅读记录 | 重读、整理、生成分享卡、查看阅读留念；保留原作链接 |

“作品详情”是所有入口共享的阅读页面。页面返回保留原有列表、专题和阅读位置。设置中放字号、配色、分类与模块管理、导入导出。

视觉采用简洁、耐读的书卷感：浅暖背景、清晰正文、少量有分寸的色彩。原文可以使用系统宋体类字体，操作说明使用易读字体。避免让复杂背景、标签墙或装饰遮过文字。

手机端单列，以一张作品卡或一段正文为中心。正文建议 18–22px 可调，保留诗行与自然换行；长篇古文自然滚动。电脑端可以并列展示作品列表与正文，避免过宽的文字行。

适配 320px 起的窄屏；主要触控区域约 44px。支持键盘、可见焦点、减少动画和字号放大。所有关键操作都有按钮，不依赖滑动、悬停或长按；打开注释后可便捷返回原文。

## 7. 配置、导入与导出

### 7.1 页面配置

- 分类：新增、改名、调整层级与顺序、停用或删除、修改作品关联；防止循环层级。
- 内容模块：新增、改名、排序、启停、设置默认展开状态；可选择文本、条目、诗句解析、关联作品等内容类型。
- 专题：编辑主题引言、选篇顺序和关联理由，复用已有作品。
- 阅读偏好：字号、配色、注释的默认显示方式。阅读深度由展开决定。
- 内容更新：通过结构化内容包导入新增作品及详解，预览变化后合并。

新增模块不会自动生成每篇作品的内容，空模块默认隐藏。大批原文、译注和赏析通过内容包维护；完整的逐篇富文本编辑不作为首版必要能力。

分类删除或合并前明确关联影响，可迁移或解除标签，不连带删除作品。模块可先停用；删除有内容的模块时展示影响并提供备份。导入校验标识、版本、引用关系与冲突，不静默覆盖用户修改；导入文本作为内容处理。

### 7.2 导出与传播

提供分享图片、内容包、个人备份和阅读 HTML 四种导出。分享图片用于保存和社交分享；内容包包含作品、分类、模块、专题与出处；个人备份包含收藏、阅读记录、阅读位置和配置；阅读 HTML 包含当前内容与配置，默认不携带个人阅读痕迹。

分享卡纳入首版，作品题名、作者或署名出处始终随选句呈现。用户也可以将内容包或 HTML 自行分享给其他人。

页面保存作用于当前浏览器；“导出文件”用于带走修改。备份带格式与内容版本，更新作品时保留稳定标识、收藏和阅读位置，遇到原文变化时尽可能合理恢复位置。

### 7.3 简要、精美的分享卡

分享卡是一张独立、可保存的图片，为手机阅读和朋友圈展示安排版式。优先使用精心排版的文字、适量留白和少量景物装饰。

#### 内容形式

| 形式 | 主要内容 | 使用场景 |
| --- | --- | --- |
| 摘句卡 | 一至四句原文、题名与作者，可附一句简短赏读 | 保存喜欢的句子、随手分享 |
| 作品卡 | 一首短诗或标明节选的完整语意片段、题名与作者，可附一句赏读 | 用一张图介绍一篇作品 |
| 阅读留念卡 | 选句、题名与作者、可选日期和个人读后感 | 自愿阅读打卡、留下某一天的心情 |

原文与署名是基础信息。日期、个人署名、读后感、简短赏读均可开关；学段和教材信息不进入默认分享版式。个人署名初始为空，读后感由用户填写；选用系统提供的赏读时明确标为“赏读”，不当作用户自己的话。

长篇优先选取短段，超出当前版式容量时提示精简选句或感想；不静默截断，不通过把正文缩到难以阅读来塞满卡片。原文与读后感在位置、字号或标签上区分，避免把现代文字误认作原作。

#### 视觉与尺寸

- 首版提供三种简洁样式：素笺（暖白与墨色）、月夜（深蓝与月色）、草木（浅绿与植物点景）。装饰随主题保持克制，正文对比度优先。
- 默认竖版 3:4，建议导出 1080 × 1440 像素 PNG；提供 1:1 方形样式，建议 1080 × 1080 像素。
- 重要文字位于安全区域，预留边距，考虑朋友圈列表预览可能发生的裁切；完整图片打开后可清晰阅读。
- 长短不同的内容使用相应排版规则。生僻字、标点避头尾、诗行与作者署名均需检查；字体用可离线使用的资源及可靠回退。
- 卡片以文学内容为视觉中心，默认不添加推广水印、二维码或学段标签。若以后提供回到作品的二维码，需要先有可公开访问的实际地址。

#### 生成、打卡与保存流程

作品或选句 → 生成分享卡 → 选择样式及比例 → 勾选日期、赏读或填写读后感 → 实时预览 → 保存图片。

“同时记下这次阅读”为独立可选项；仅在用户明确选择并保存记录时，记录作品、选句、日期、感想和样式。取消制卡、单纯预览或重复保存图片不自动新增阅读记录。记录可编辑、删除，并从“收藏”中的阅读记录再次生成卡片；不将出图当作已读完或已掌握的证明。

图片在本地生成，核心出图流程可离线完成。支持下载的浏览器提供下载按钮；手机端同时提供图片预览，以便在支持的环境中长按保存。可选调用系统分享面板时先检测能力，失败或取消后保留预览与保存入口。

朋友圈的可靠流程为“生成图片 → 保存到设备／相册 → 用户自行发布”。普通 HTML 不承诺直接发布到朋友圈；系统分享面板是否出现微信，以及保存到相册的具体步骤，以实际设备和浏览器能力为准。

首版记录以结构化内容保存，不在浏览器存储中大量堆积高清图片。重新生成时使用记录中的选句与当时署名，若源作品已修订，提示可选用修订内容，避免无提示改写个人留念。

## 8. 内容建设与可信度

原始需求中的全国中小学古诗文范围继续作为首批内容整理依据，并扩充内容契合、文学价值明确的优秀作品。选篇、编排和推荐以文学内容为中心，教材与课程材料用于内部核查覆盖范围。

不建立年级、册次、单元等产品分类，也不将背诵要求转成面向读者的功能。必要的选篇依据留在编辑资料中，学段只转为简单标签。无依据的标签不补造，教材外作品不强行分配学段。

文本核对包括篇名、署名、原文、标点、版本、节选范围、注音、注释和关联引用；作者生平与创作背景采用可信资料。不同版本、佚名、作者归属争议等按真实情况记录。现代译注与赏析自行组织表达并保留参考资料。

现有 `base/base-note.md` 保留为待校核的候选篇目材料，其中的数量口径、类别混用和无原文依据的标签需修正。例如《鹿柴》的“月”与《风》的“雪”标签不能直接沿用。已知数量不作为当前收录完整性的证明。

作品、作者、分类、专题、内容模块和资料来源分别维护并相互引用。同一作品不因学段标签或专题不同而复制；同题作品用作者、首句等区分，组诗与节选保持完整关系。

## 9. 单文件交付

最终交付内置内容、样式和交互的 HTML。核心阅读、分类、搜索、收藏、分享卡生成与配置可离线使用，不依赖外部接口、在线字体或 CDN。内部资料可分开维护，交付时生成一个文件。

收藏、自愿保存的阅读记录、阅读位置与配置保存在当前浏览器，提供备份迁移与存储失败提示。不同设备之间通过导入导出迁移，不默认自动同步。

移动端需验证浏览器中的实际打开方式；部分聊天工具和系统文件预览器无法运行脚本。若之后需要更方便地通过链接传播，可另行选择静态托管同一份 HTML，当前不自动发布。

音频和插画后续按内容需要选择，考虑单文件体积、离线使用、读音准确性与资料来源。

## 10. 实施顺序与验收

### 建议顺序

1. 确认本次调整后的产品方向、阅读路径与卡片内容结构。
2. 核查内容池与分类词表，选取约 12–18 篇代表性作品，覆盖不同景物、情感、作者和文体，写出完整阅读内容。
3. 实现随读、寻篇、详情、收藏与分享卡，并验证自然的关联阅读、移动端呈现、图片保存、自愿阅读记录、配置和备份。
4. 补齐核定内容范围，持续加入优秀作品与专题，输出完整单文件 HTML。

代表性样例用于确定内容与体验标准，不替代最终完整内容整理。每篇作品都应具备原文、作者或出处信息，以及适用的背景和赏读；不适用或无从确定的内容如实处理。

### 验收重点

- 打开页面能立即读到作品，第一感受来自原文和呈现。
- 可以从一个景物或一份心情找到作品，并沿具体关联继续阅读。
- 详情中的作者、背景、手法、思想等内容充分、可查，又不会一次全部压在读者面前。
- 小学、初中、高中只作为辅助标签，阅读路径与界面不受学段组织支配。
- 卡片有阅读与探索价值，不出现练习、自评、考核、任务队列、进度排名等功能。
- 原文与讲解准确，关联理由有内容支撑；事实和阐释区分清楚。
- 收藏作品与句子可回到原文；重读、返回、注释展开均保留合理位置。
- 可从作品、选句和收藏生成图片；PNG 清晰完整，题名与署名准确，节选与原文内容匹配，个人感想有清楚区分。
- 三种卡片形式与两种比例都能正确处理长短内容；预览与导出一致，文字不溢出、不被裁切，移动端保存有可用路径。
- 日期、个人署名、赏读和读后感可选；自主打卡可查看、编辑、删除和备份，不出现连续天数压力或任务提醒。
- 出图和图片保存失败时可重试并保留配置；预览、取消、重复保存不会误增阅读记录。
- 分类、模块和专题的修改能正确影响页面，导入导出可恢复内容、收藏及设置。
- 手机与电脑的文字和操作清晰可用，离线可完成核心阅读。

样例评审关注读者是否愿意停留、是否产生新的好奇、是否能找到下一篇想读的作品。以实际阅读反馈评估这些目标，不用答题正确率、背诵量和连续打卡代替文学体验。
